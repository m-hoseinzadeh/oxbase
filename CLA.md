## How to sign

The first time You open a pull request, the CLA Assistant bot comments with instructions. Reply
on the pull request with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username, user ID, the pull request and the time are recorded in the
`cla-signatures` branch of this repository. You only need to sign once; this covers all of Your
future Contributions to the Project.
