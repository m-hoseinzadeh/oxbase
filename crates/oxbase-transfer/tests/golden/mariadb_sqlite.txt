float32                  -> float64                              widened     SQLite floats are 64-bit: every value is kept
float64                  -> float64                              exact

decimal                  -> decimal(65,30)                       widened     more than 15 digits: declared DECIMAL_TEXT, so the exact text is kept (it compares and sorts as text)
char(10)                 -> char(10)                             widened     SQLite does not enforce text lengths: every value is kept

varchar                  -> text                                 exact
text                     -> text                                 exact

varbinary                -> varbinary                            exact
date                     -> date                                 widened     SQLite has no date and time types: stored as ISO-8601 text

json                     -> json                                 widened     SQLite has no JSON type: stored as JSON text
