# SQLite -> SQL Server
boolean                  -> boolean                              exact
int8                     -> int64                                exact
int16                    -> int64                                exact
int32                    -> int64                                exact
int64                    -> int64                                exact
int32 unsigned           -> int64                                exact
int64 unsigned           -> text                                 exact
float32                  -> float64                              exact
float64                  -> float64                              exact
decimal(18,4)            -> decimal(18,4)                        exact
decimal(38,10)           -> decimal(38,10)                       exact
decimal                  -> decimal(38,10)                       narrowed    unconstrained decimals become decimal(38,10): values with more than 28 integer digits are refused, more than 10 decimal places are refused
char(10)                 -> char(10)                             narrowed    nchar lengths count UTF-16 code units, and characters outside the BMP take two: a value with them can exceed nchar(n) and is refused
varchar(255)             -> varchar(510)                         widened     nvarchar lengths count UTF-16 code units, and characters outside the BMP take two: stored as nvarchar(510) to hold 255 characters
varchar                  -> text                                 exact
text                     -> text                                 exact
binary(16)               -> varbinary                            exact
varbinary                -> varbinary                            exact
date                     -> date                                 exact
time(6)                  -> time(6)                              exact
timestamp(6)             -> timestamp(6)                         exact
timestamptz(6)           -> timestamptz(6)                       exact
interval                 -> text                                 exact
uuid                     -> uuid                                 exact
json                     -> json                                 exact
jsonb                    -> jsonb                                exact
int32[]                  -> text                                 exact
text[]                   -> text                                 exact
enum(small, medium, large) -> text                                 exact
geometry                 -> text                                 exact
